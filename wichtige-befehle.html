Wichtige Linux-Befehle

Die folgenden Befehle gehören zu den grundlegenden Linux-Befehlen und sind distributionsübergreifend in Debian, Ubuntu und Gentoo verfügbar. Unterschiede gibt es hauptsächlich bei der Paketverwaltung und einigen distributionsspezifischen Werkzeugen.

  pwd    → Aktuelles Verzeichnis
  ls     → Dateien und Ordner auflisten
  cd     → Verzeichnis wechseln
  mkdir  → Verzeichnis erstellen
  touch  → Datei erstellen
  cp     → Datei kopieren
  mv     → Verschieben / Umbenennen
  rm     → Datei löschen
  cat    → Dateiinhalt anzeigen
  chmod  → Rechte ändern
  sudo   → Administratorrechte
  ps     → Prozesse anzeigen
  top    → Systemüberwachung
  ping   → Netzwerk testen
  ssh    → Remote-Verbindung

Software installieren

Linux bietet Paketverwaltungen, mit denen Programme einfach installiert,aktualisiert und entfernt werden können. 

Debian/Ubuntu:
sudo apt update
sudo apt install paketname

Gentoo:
sudo emerge paketname

Benutzerverwaltung

whoami      → Aktuellen Benutzer anzeigen
passwd      → Passwort ändern
id          → Benutzer- und Gruppeninformationen

Festplatten und Speicher

df -h       → Festplattenbelegung anzeigen
du -sh      → Größe eines Verzeichnisses anzeigen
free -h     → Arbeitsspeicher anzeigen

Dateien suchen

find        → Dateien suchen
locate      → Schnelle Dateisuche
grep        → Nach Text in Dateien suchen
